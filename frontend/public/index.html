AI Agent Hub is a pay-per-call API platform for AI agents

Every call is billed automatically in USDC using the x402 protocol - there is no API key, no account, and no signup. Agents get instant access to data queries, file storage, and ad impressions, paying only for what they actually use. The same tools are also exposed natively over MCP, so any MCP-capable agent can discover and call them directly without touching the REST API at all.

POST /api/queries

Run a paid data query.

$0.01

POST /api/storage/upload

Store a file.

$0.05

GET /api/storage/:id

Download a stored file.

$0.01

POST /api/ads/impression

Buy an ad impression.

$0.001

MCP endpoint

/mcp

Point any MCP-capable agent at this URL to discover the tools above.
